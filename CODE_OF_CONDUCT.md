# Code of Conduct

## Our standard

This project welcomes rigorous technical disagreement. Critique claims, methods, experiments, and evidence directly while treating contributors professionally.

Expected behavior includes:

- making technical criticism specific and evidence-based
- documenting failures without embarrassment or blame
- distinguishing observations from interpretations
- giving others enough information to reproduce a result
- acknowledging uncertainty and conflicting evidence

Unacceptable behavior includes harassment, personal attacks, discriminatory conduct, deliberate disruption, or knowingly falsified experimental results.

## Enforcement

Repository maintainers may edit, remove, or reject contributions and interactions that violate these standards.
