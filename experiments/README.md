# Experiments

Each experiment should have its own directory containing a short README and enough raw evidence to reproduce the result.

Recommended naming:

`YYYY-MM-DD-short-experiment-name`

Suggested starting experiments:

1. Fair Price — full-transcript reconstruction
2. Fair Price — artifact-only reconstruction
3. Fair Price — minimum recovery-floor experiment
4. Fair Price — repeated reconstruction on the same model
5. Fair Price — cross-model reconstruction
6. Development-cycle comparison against a bounded conventional implementation
