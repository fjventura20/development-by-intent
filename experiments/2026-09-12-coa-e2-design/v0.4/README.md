# COA-E2 v0.4.1 package

Targeted one-pair proof of concept. This directory is draft-only and not
frozen. The only controlling packet is
`packets/CANONICAL-INITIALIZATION-TEMPLATE-DRAFT.md`; the only participant
prompts are `tasks/participant/U2.md`, `U3.md`, and `U5.md`. Outcome
mappings exist only in `tasks/RUBRIC-DRAFT-v0.4.1.md`.

The controlling deviation document is
`DEVIATION-AND-STOP-RULES-DRAFT-v0.4.1.md`. The controlling protocol is
`PROTOCOL-DRAFT-v0.4.1.md`.

Two isolated profiles, two sessions, six turns per session, 12 experimental
turns total. No final nonces, profile creation, mechanism test, participant
invocation, scoring, evaluator, or freeze is authorized.

This v0.4.1 package patches v0.4 in place in response to the PI NO-GO
ruling. The directory is still `v0.4/`; the filename suffixes identify the
patched versions. There is no `v0.4.1/` sibling subtree.
