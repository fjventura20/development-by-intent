## 1. Research question

> **When a targeted intent change is expressed through a frozen INSA v0.3 evolution contract, can the intelligent execution environment implement the declared target behavior while preserving a predeclared non-target Behavioral Identity envelope?**

The required conjunction is:

```text
Target Modification Success
AND
Non-target Identity Preservation
```

Neither component alone constitutes `EVOLUTION_PASS`.

## 2. Research posture

This study is a **post-failure architectural intervention experiment**, not an independent replication.

The prior DbI Evolution experiment used the same Amazing Birthday target mutation and ended in a substantive modification-and-preservation failure. INSA v0.3 was developed afterward and makes evolution constraints explicit through a frozen baseline and target/preservation contract.

Reusing the same target is deliberate because it preserves comparability on a known difficult mutation.

### Claim restraint

Even if INSA-ID-E1 passes, the project MUST NOT claim that the INSA contract causally outperformed the prior modification mechanism. A contemporaneous randomized legacy-vs-INSA mechanism experiment would be required for that claim.

Historical comparison is descriptive only.

### 5.3 Session isolation

## 7. Behavioral dimensions

### 7.1 Dimension universe

```text
D = M ∪ P ∪ O
M ∩ P = ∅
M ∩ O = ∅
P ∩ O = ∅
```

### 7.2 M — Mutation dimension

**M1 — Nearby worldwide-historical connection**

Add exactly one historically significant worldwide event occurring within ±30 calendar days of the supplied birth date and clearly distinguish it from exact-date connections.

### 7.3 P — Preservation dimensions

**P1 — Exact-date preference**  
Exact-date connections retain priority and are clearly distinguished from nearby context.

**P2 — Connection-count selectivity**  
Total selected connections remain 5–10, **including the new nearby event**. The system must rebalance selection rather than simply append an 11th connection when necessary.

**P3 — Selection significance**  
Connections remain historically meaningful rather than filler.

**P4 — End-of-report synthesis**  
A meaningful synthesis remains present.

**P5 — Lifetime framing**  
The report continues to connect the birthdate with the person's lifetime/historical arc where appropriate.

**P6 — Warm / vivid narrative voice**  
The established recognizable narrative style remains.

**P7 — Factual discipline**  
Nearby material is not represented as exact-date material; factual/date discipline remains intact.

**P8 — Avoidance of arbitrary trivia**  
Weak filler, arbitrary trivia, or celebrity-only padding does not substitute for significance.

### 7.4 O — Out of scope

Unless they cause an M/P failure, these do not constitute identity failure:

- exact wording;
- sentence / paragraph order;
- harmless length variation;
- specific examples selected;
- code / tool strategy;
- internal plan;
- model implementation mechanism.

`O` cannot be expanded after outputs exist.

## 8. V(d) — Permitted variance

Variance attaches to a dimension; it is not a separate dimension class.

### 8.1 Calibrated BIB identity dimensions

Retain the prior calibrated preservation thresholds unless a pre-execution review explicitly changes them:

- Arm G within-reconstruction Manhattan mean ≤ Arm C mean + **1.5**;
- Arm G within-reconstruction Manhattan mean ≤ **2.5 absolute**;
- Arm C must satisfy the frozen BIB non-deviated envelope on its own with **no added treatment tolerance**.

### 8.2 P-axis aggregate tolerance

Retain the prior per-axis collapse rule:

An axis is `BROKEN` for an evaluator when BOTH:

- Arm G failure rate on that axis ≥ 30%;
- Arm G failure rate ≥ 30 percentage points worse than Arm C.

Any one `BROKEN` P axis causes preservation failure for that evaluator.

### 8.3 No post-hoc tolerance changes

All `V(d)` rules must be frozen before generation.

## 9. Mutation acceptance A

Every candidate receives four objective mutation checks in the separate mutation-evaluation pass:

- **A1:** a qualifying event within ±30 calendar days is included;
- **A2:** exactly one such event is included;
- **A3:** it is clearly distinguished from exact-date connections;
- **A4:** it passes the frozen worldwide-historical-significance rubric.

`modification_conformance = A1 + A2 + A3 + A4`, range 0–4.

### 9.1 Worldwide-historical-significance rubric

A nearby event passes A4 only if at least two of four are satisfied:

1. mainstream historical/reference treatment as internationally or world-historically significant;
2. material involvement/effect across multiple sovereign states or major regions;
3. durable consequences extending materially beyond place of origin;
4. reasonable inclusion in a concise global-history chronology for that year.

No date-specific examples are permitted in evaluator materials.

### 9.2 Mutation-success gates

Require independently for both mutation evaluators:

- **G_mod_a:** Arm G mean modification_conformance ≥ 3.5 / 4.0;
- **G_mod_b:** ≥ 80% of Arm G candidates pass A1–A4;
- **G_mod_c:** each Arm G reconstruction has ≥ 70% all-pass candidates;
- **G_mod_d:** Arm G all-pass rate exceeds Arm C all-pass rate by ≥ 50 percentage points.

Evaluator scores are not pooled.

---

## 10. Preservation gates G

Require independently for both identity evaluators:

1. BIB calibrated 4-dimensional preservation criteria pass;
2. no P axis is `BROKEN`;
3. identity-preservation inter-evaluator agreement ≥ **0.9**;
4. per-dimension inter-evaluator MAE ≤ **1.0**;
5. factual-discipline preservation remains evaluable and intact.

No pooled average may rescue an identity-preservation failure by one evaluator.

## 16. Outcome logic

### Precheck gate

Architecture binding, source binding, contract binding, corpus binding, evaluator availability, evidence integrity, blinding/lock integrity, and Arm C validity must all PASS.

### Substantive components

```text
Modification Success
  = G_mod_a AND G_mod_b AND G_mod_c AND G_mod_d
    for both mutation evaluators

Identity Preservation
  = calibrated preservation gates
    AND no P-axis BROKEN
    AND agreement ≥ 0.9
    AND per-dim MAE ≤ 1.0
    for both identity evaluators
```

### Joint disposition

```text
Modification TRUE + Preservation TRUE
  -> EVOLUTION_PASS

Modification FALSE + Preservation TRUE
  -> MODIFICATION_FAILURE

Modification TRUE + Preservation FALSE
  -> PRESERVATION_FAILURE

Modification FALSE + Preservation FALSE
  -> MODIFICATION_AND_PRESERVATION_FAILURE
```

`INCONCLUSIVE_PENDING_FURTHER` is only for residual ambiguity not covered by substantive outcomes.
