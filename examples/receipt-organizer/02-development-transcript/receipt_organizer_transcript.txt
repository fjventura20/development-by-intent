## Architecture

**3 files:**

### `storage.py`
- Stores receipts as JSON in `~/.receipt_organizer/receipts.json`
- Duplicate detection via fingerprint: `sha256(merchant|date|total)[:16]`
- Functions: `save_receipt()`, `find_duplicate()`, `all_receipts()`

### `organizer.py`
- **Extract** — sends raw receipt text to Claude with a structured JSON schema tool, gets back `{merchant, date, line_items, subtotal, tax, total, payment_method, category}`
- **Query** — sends the user's natural-language question + the full receipt history as JSON context, asks Claude to answer it

### `main.py`
- REPL loop: reads multi-line input until the user enters a blank line
- Heuristic: if input looks like a receipt (has price patterns), it extracts + saves; otherwise it's a query
- Prints structured confirmation on save, or Claude's answer on query
