# Fair Price — Canonical Example

**Status: being rebuilt for publication**

Fair Price is intended to be the first fully reproducible Development by Intent example.

## Application purpose

For a requested homeowners-association service or project, Fair Price researches enough current information to answer the practical question:

> **What should we reasonably expect to pay?**

A normal result should emphasize a recommended budget and a defensible fair-price range without turning the answer into an unnecessarily complicated consulting report.

## Why this example

Fair Price is useful as a research specimen because it combines:

- current external research
- judgment rather than simple retrieval
- user-defined output constraints
- iterative conversational refinement
- domain-specific expectations
- behavior that can be tested by examples

while remaining small enough for independent reconstruction.

## Planned publication artifacts

- `original-transcript/` — complete source conversation used to develop the new canonical version
- `preserved-artifacts/` — checkpoints/specifications produced during preservation
- `reconstruction/` — instructions and evidence from independent reconstruction attempts
- `tests/` — behavioral baseline and test cases

No legacy Fair Price behavior should be silently imported into the canonical example. The published baseline should come from a clean, from-scratch development transcript.
