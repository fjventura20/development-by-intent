# Terminology

## Development by Intent (DbI)
A software-development approach in which application behavior is shaped through expressed intent, examples, constraints, tests, and conversational refinement against a capable AI substrate.

## Conversational application
An application whose defining behavior is materially established through interaction with an AI system rather than only through conventional source-code implementation.

## Original development transcript
The conversation in which the application's behavior was initially created and refined.

## Preservation checkpoint
A durable artifact created at a known point in development that records enough behavior, constraints, examples, and tests to support later recovery.

## Reconstruction
The act of creating a fresh instance of the application from preserved source material.

## Recovery fidelity
The degree to which a reconstructed instance reproduces the intended behavior of the baseline application.

## Behavioral baseline
A defined set of expected behaviors against which reconstructions or modifications are compared.

## Recovery floor
The smallest known set of preserved artifacts that still produces acceptable recovery fidelity.

## Generation artifact
Behavior that appears in an application output or implementation without having been explicitly specified or reliably encoded in the preserved source material.
